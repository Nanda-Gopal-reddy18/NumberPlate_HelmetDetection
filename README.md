# An Intelligent Vision Based System for Vehicle Identification and Helmet Detection

This repository hosts the production-ready Docker container configuration for the Intelligent Vision-Based Traffic Safety Portal. The system runs on a CPU-optimized environment, detecting helmet compliance violations and extracting vehicle license plates.

### Core Technology Stack:
* **Backend**: Flask, Gunicorn
* **Inference Engine**: OpenCV DNN (YOLOv3), PyTorch (YOLOv5)
* **OCR**: EasyOCR
* **Frontend**: Vanilla HTML5, CSS3, JavaScript
